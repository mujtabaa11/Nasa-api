# NASA Astronomy Picture of the Day (APOD) Viewer  

## Overview  

This React application showcases NASA's **Astronomy Picture of the Day (APOD)**, fetching and displaying a new photo daily from NASA's APOD API. The app provides stunning space imagery and accompanying descriptions, making the wonders of the universe accessible to visitors in an engaging way.  

👉 **Live Demo**: [NASA APOD Viewer](https://master--nasaapod-react-app.netlify.app)  

---

## Features  

- **Daily Space Images**: Fetches and displays the Astronomy Picture of the Day.  
- **Informative Descriptions**: Displays details about each image, including title, date, and explanation.  
- **Responsive Design**: Seamlessly adapts to various screen sizes.  
- **Intuitive Interface**: Minimalistic and user-friendly design for easy navigation.  

---

## Technologies Used  

- **Frontend**: React.js  
- **API**: NASA's Astronomy Picture of the Day (APOD) API  
- **Hosting**: Netlify
